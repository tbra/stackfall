# Stick motion, clicks and combo specimens

Original path-based vector art generated by tools/generate_pad_motion_glyphs.py.
Eight direction glyphs cover left/right sticks and up/down/left/right. Two click
glyphs cover L3/R3. All use64x64viewBoxes and the existing paper/ink/cyan palette.
Pale under-strokes keep directional marks visible over dark backgrounds.

The two combo specimens are160x64:RT+right stick andLB+RB. Each component retains
its original64-unit height,with outer padding and a contrast-protected plus sign.
They illustrate default controls only. Bindings are remappable: production prompts
must compose the current InputEvents' individual glyphs and a separator at runtime.
Do not hard-code these combo examples as a remapped action's binding display.
No input mapping,InputGlyph or Options code changes are included.

Catalog:gamepad_motion_catalog.json. It records file,meaning,viewBox dimensions,
side/direction or combo components. No third-party artwork or embedded fonts;
letter and number legends are vector paths. Existing button/stick art is composed
into the combo examples without editing those original files.

## Reproduce

Run python tools/generate_pad_motion_glyphs.py. Copy the helper
source_art/pad_motion_glyphs_v1/project.godot.review into a temporary directory as
project.godot and copy rasterize.gd beside it. Launch that isolated project
headlessly with -s rasterize.gd -- <absolute glyph directory> <TEMP directory named
codex_pad_motion_rasters>. Then run python tools/generate_pad_motion_glyphs.py --review.
The helper project is stored as .review to avoid a nested Godot project warning.

Review:docs/art_mockups/pad_motion_glyphs_v1/review.png;36native Godot rasters at
24/32/48px,light/dark/grayscale. Verifier checks exact dimensions,transparent outer
padding,unique silhouettes at each size and both combo components. XML/catalog and
Python syntax checks also pass. Final native run exit0,noerrors/warnings;log
Windows TEMP/codex-pad-motion-native-contrast.log. Initial padding and contrast
findings were fixed before handoff. No game suite/window probe or live UI acceptance.
Claude reviews/integrates and applies the existing shared UI scaling rule.

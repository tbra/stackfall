# Speaker icon art candidates

Four standalone SVG sources for muted, low, mid and high volume. They share a paper speaker casing, coral inset, dark outline and increasing sound-wave count. The mute state uses an X as a second cue. These are **candidates** named `*_art.svg`; the live `speaker_*.svg` icons and UI preload paths remain untouched.

Each source uses a 64×64 viewBox, explicit vector paths, and no font, filter or raster dependency. The waves have a pale outer stroke so their dark ink remains visible over a dark sky. Evaluate the four states at 24 and 32 px on both light menu panels and dark backgrounds before replacing the live set. State remains legible without color.

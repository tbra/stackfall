# Weather ambience and gust candidates

Original procedural weather Foley generated by `tools/generate_weather_audio.py`.
No recordings or existing sound assets are sampled. Three 32-second stereo loops
cover rain, quiet snowfall hush and storm wind. Three finite stereo whooshes cover
short/medium/long gusts. Every file is 44.1 kHz, 16-bit PCM WAV.

Rain combines airy periodic noise and sparse circular droplets. Snow is a quiet
filtered hush, deliberately below the other beds. Storm wind combines low body
and an airy layer with slow swells. Gusts use finite noise-band sweeps with smooth
attack and release, without pitch tones or long reverberation.

## Loop playback

Loop the complete rain/snow/storm files forward. `manifest.json` records begin
frame 0 and exclusive end frame 1,411,200 for all three loops. Enable forward
looping during import or through the existing audio setup; WAV files do not
implicitly turn into looping resources. Leave all gust files in one-shot mode.
Preserve the existing gust suppression/pause during storms from mp0.91.
Use the existing weather scheduler, transitions and audio settings; these assets
do not redefine which effects can coexist.

The beds use periodic Fourier noise, integer-period slow envelopes and circular
rain droplet placement. A circular rotation chooses a quiet digital seam; there
is no fade-to-silence at each wrap. The delivered PCM seam jump and curvature are
below the internal 99th percentile of the same differences on both channels.
First/last one-second RMS differs by less than 0.36 dB. Loop bounds are verified
against actual container frame counts. This is technical seam evidence, not
subjective listening or runtime import acceptance.

## Validation and review

`python tools/generate_weather_audio.py` reproduces all six WAVs, manifest and
review. Format/container roundtrip, stereo channels, durations, headroom, DC,
mono compatibility, seam statistics, finite gust endpoints/tails, unique hashes,
and identical hashes after regeneration passed. Stereo correlation is about
0.64 and downmix loss about 0.86 dB. Gust tail RMS is below -67 dBFS.
Generator syntax and diff checks pass. No Godot, game window, test suite, benchmark
or automatic audio playback was used.

See `docs/art_mockups/weather_ambience_v1/signal_review.png` and `audition.wav`.
The audition plays each loop's last three seconds followed by its first three,
then the gusts; `audition_timeline.json` labels exact seam times. Stored levels
are preserved. Signal plots are scaled per cue and do not compare loudness.
Claude/owner should listen for timbre, repetition, seam audibility and the actual
music/weather mix before accepting these asset candidates.

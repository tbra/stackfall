# Effect sounds

## gift_spawn_jingle.wav

Three-note chime played when a gift crate starts descending
(`AudioConfig.gift_spawn_file`, `Sfx._on_gift_flight_spawned`). It was
synthesized by the Codex agent on 2026-10-02 for this project (Bontago-mp0.23).
No third-party samples were used. The repository has no synth/generator tool
for effects, and the generating script was not kept.

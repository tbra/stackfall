# Earthquake gift candidate

Faceted fractured tablet for the held earthquake gift. The dark base, two weathered brass plates, and coral zigzag fault preserve the current scene's visual language while making the split readable from an oblique camera. The plates carry a gentle, one-second `quake_pulse_1s` loop; the base and fault stay fixed.

Files: `earthquake_v1.glb` for import and `earthquake_v1_preview.png` for review. Editable Blender source is in `source_art/earthquake_v1/earthquake_v1.blend`; `tools/generate_earthquake_model.py` rebuilds both exports with Blender 4.5.

This is an asset candidate only. The held-gift scene has not been changed. Review in the actual game camera before replacing its existing geometry, particularly whether the gold faces overpower the coral fissure at small scale.

# Bomb gift model candidate

Low-poly charcoal bomb with a blue-gray socket, bent cream fuse, and coral/gold ignition spark. The large shell and distinct fuse read from a moving held-gift camera; the mesh contains no camera, light, or gameplay logic.

`bomb_v1.glb` is the import candidate and `bomb_v1_preview.png` is a neutral render. Editable source is `source_art/bomb_v1/bomb_v1.blend`; rebuild with Blender 4.5 using `tools/generate_bomb_model.py`.

Review at actual held-gift size before replacing the existing `assets/gifts/held/bomb.tscn` geometry. The spark is static and may be animated by the game scene if desired.

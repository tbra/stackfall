# Gift crate model study

Original tabletop gift crate, generated in Blender 4.5 by `tools/generate_gift_crate_model.py`. The script is the reproducible source; `source_art/gift_crate_v1/gift_crate_v1.blend` retains the editable objects, materials, camera and lights. That folder has `.gdignore` so Godot imports the `.glb` rather than attempting to import the Blender source. The `.glb` contains only the crate objects. The PNG is a neutral review render.

The crate is about 1.1 × 1.1 × 1.1 Blender units with its origin at the bottom center. It uses broad warm panels, coral frame, brass ribbon and a teal front seal to stay readable at gameplay camera distance. There are no external textures, downloads or third-party meshes. It is an **asset study**; no live game scene references it yet.

Review in Godot with a bright sky and storm background before choosing it as a production gift crate. Check the front seal's orientation and the model's apparent scale beside an ordinary block.

# Faceted volcano gift candidate

`volcano_v1.glb` is an original held-gift art candidate: a hollow, irregular slate cone with a visible crater pool and three broad lava rivulets. Coral and brass lava distinguish it from the dark rock without relying on tiny detail. The model is about 0.9 units wide and 0.7 units high, with a center pivot. The GLB contains model meshes only.

`source_art/volcano_v1/volcano_v1.blend` is editable Blender source under `.gdignore`. `volcano_v1_preview.png` is a neutral-light 960 × 720 review render. Rebuild with Blender 4.5: `blender -b --python tools/generate_volcano_model.py`.

This is a candidate only. `assets/gifts/held/volcano.tscn` remains active; no scene or game logic is changed.

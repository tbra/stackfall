# Faceted glue jar gift candidate

`glue_v1.glb` is an original low-poly held-gift art candidate. Its mint faceted jar, dark twist cap, paper label, and brass drop mark remain distinct at small sizes. The model is about 0.6 units wide and 1.0 unit tall with a center pivot. The GLB includes only model meshes; the camera, lights, and floor stay in the Blender source.

`source_art/glue_v1/glue_v1.blend` is editable source under `.gdignore`. `glue_v1_preview.png` is the neutral-light review image. Rebuild with Blender 4.5: `blender -b --python tools/generate_glue_model.py`.

This is a candidate only. The existing `assets/gifts/held/glue.tscn` remains active; no scene or game logic is changed.

# Black hole gift model candidate

Dark faceted core with violet and amber 3D accretion rings. Asymmetric fragments on both rings make their counter rotation visible from a moving camera. The exported GLB contains one four-second `orbit_4s` animation with two pivot rotation tracks.

`black_hole_v1.glb` is the import asset; `black_hole_v1_preview.png` is a neutral render. Editable source is `source_art/black_hole_v1/black_hole_v1.blend`; regenerate with Blender 4.5 using `tools/generate_black_hole_model.py`.

This package does not change the live held-gift scene. Review in its actual camera and at held-gift scale before replacement. The dark core uses low specular response to preserve a void-like center under bright lighting.

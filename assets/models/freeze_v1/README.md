# Faceted freeze gift candidate

`freeze_v1.glb` is an original, low-poly freeze gift art candidate. A beveled teal core holds four asymmetric crystal shards, with a dark cross mark on the front so the silhouette remains legible in desaturated lighting. The model is about 0.9 units wide and 1.1 units tall, with a center pivot. The GLB contains only model meshes.

`source_art/freeze_v1/freeze_v1.blend` is editable Blender source under `.gdignore`. `freeze_v1_preview.png` is a neutral-light 960 × 720 review render. Rebuild with Blender 4.5: `blender -b --python tools/generate_freeze_model.py`.

This is an art candidate. `assets/gifts/held/freeze.tscn` remains active; no scene or gameplay logic is changed.

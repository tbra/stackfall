# Beads (Stackfall)

All work is tracked in `bd`. The project rules for Beads (who claims, comments and closes; `--actor`; no Beads remote; memories by key) are in CLAUDE.md §Beads and §Git authority and override generic bd guidance.

- `python tools/board_brief.py` or `bd ready`: what can start now
- `bd show <id> --json --brief-deps`: one issue without comment bodies
- `bd comments add <id> --actor <profile> "..."`: a checkpoint on your assigned issue
- `bd memories <key>`: one stored memory; `bd remember --key <key> "..."`: store reusable knowledge, not progress

# Gift spawn jingle candidate

`assets/effects/gift_spawn_candidate.wav` is a 1.35 second, original four-note rising chime (C5–E5–G5–C6). It is a dry mono 44.1 kHz, 16-bit PCM asset. `tools/generate_gift_spawn_jingle.py` contains the entire synthesis source; it uses no sampled or licensed audio.

This is a candidate for the moment a gift enters the arena. Audition it alongside existing match effects, including repeated spawns, and adjust level or tone before wiring it into the game. Its ending releases to silence. No live audio configuration is changed in this package.
